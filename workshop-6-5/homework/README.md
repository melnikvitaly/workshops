6.5 Апаратна частина:

ESP32-S3 DevKit.
Кнопка 1 (Імітує оптичний датчик — лічить деталі).
Кнопка 2 або вбудована BOOT (Аварійна зупинка).
Світлодіод (Індикатор тривоги).
Вільний пін АЦП (Або будь-який реальний датчик, наприклад, температури).

Що треба реалізувати (Логіка роботи):

Глобальний лічильник деталей:
Кнопка 1 викликає апаратне переривання (ISR). Всередині ISR ви маєте збільшити глобальний лічильник на +1. Цей лічильник будуть читати інші задачі.

Формування системного звіту:
У вас є один глобальний масив-рядок для звіту.

Task 1 (працює на Core 0): Раз на секунду читає глобальний лічильник, вираховує швидкість конвеєра (деталі/хв) і форматує ці дані у спільний буфер звіту.

Task 2 (працює на Core 1): Раз на секунду читає показники з АЦП (шум або реальний датчик) і дописує їх у той самий спільний буфер.

Аварійна зупинка системи:
Кнопка 2 викликає переривання (ISR). Також у вас є Task 3 з найвищим пріоритетом у системі. У нормальному стані Task 3 повинна "спати", не споживаючи процесорного часу.
Коли спрацьовує кнопка 2, Task 3 має миттєво прокинутись, увімкнути світлодіод, безпечно записати у буфер звіту фразу "SYSTEM HALTED!" і заблокувати подальшу роботу конвеєра.
