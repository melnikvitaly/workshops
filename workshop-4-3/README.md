# Реалізація

Проєкт [`workshop-4-3/`](workshop-4-3/) (STM32CubeIDE, STM32F401CCU6) — це
mini-project 4 без ESP32: SPI-канал, OLED-дисплей і потоковий ADC+DMA прибрано,
на шині I2C1 лишились тільки RTC і EEPROM, а виводом став TTL-USB конвертер.

## Розводка (та сама, що в mini-project 4)

| лінія                 | пін        | пристрій                                                          |
| --------------------- | ---------- | ----------------------------------------------------------------- |
| ADC1_IN0              | PA0        | дільник з фоторезистором (LDR)                                    |
| I2C1_SCL / I2C1_SDA   | PB6 / PB7  | DS1307 RTC (0x68) + AT24C32 EEPROM (0x50) — одна шина, дві адреси |
| USART1_TX / USART1_RX | PA9 / PA10 | TTL-USB: PA9 -> RX конвертера, PA10 <- TX конвертера              |
| GND, 3V3              | —          | спільні для всіх модулів                                          |

Монітор порту: **115200 8N1**. Підтяжки SDA/SCL уже стоять на модулі RTC.

## Що робить прошивка

1. На старті піднімає консоль і пише, чи відгукнулись RTC та EEPROM.
2. Якщо DS1307 стоїть (біт CH), запускає його і просить виставити час.
3. **Зчитує весь журнал з EEPROM і виводить у монітор порту** — це пункт
   завдання про читання EEPROM; журнал переживає перезавантаження, бо вказівник
   наступного запису лежить у самій пам'яті (перші два байти).
4. Далі раз на `LOG_INTERVAL_MS` (`Inc/config.h`, зараз 5 с) міряє освітлення,
   бере час з RTC і дописує запис у EEPROM, дублюючи рядок у монітор порту.

Один запис — 8 байтів, вирівняних по межі сторінки EEPROM:

```
[0] місяць  [1] число  [2] рік      -> мм:дд:гг
[3] години  [4] хвилини [5] секунди
[6..7] сире 12-бітне значення АЦП (Big-Endian)
```

4 КБ AT24C32 = 511 записів.

## Команди в моніторі порту

| команда                  | що робить                                       |
| ------------------------ | ----------------------------------------------- |
| `help`                   | коротка довідка                                 |
| `now`                    | поточний час з RTC + поточне освітлення         |
| `dump`                   | вивести весь журнал з EEPROM                    |
| `clear`                  | почати журнал спочатку                          |
| `time YY MM DD hh mm ss` | виставити годинник, напр. `time 26 8 8 14 30 0` |

⚠️ Команда виконується по CR або LF, тож монітор порту має надсилати кінець
рядка: у Serial Monitor (VS Code) поле "Line ending" -> `LF` або `CRLF`, у
PlatformIO — `--eol LF`. З "Line ending: None" набране слово просто лежатиме в
буфері і нічого не станеться.

Приклад виводу:

```
=== workshop-4-3: light log with RTC timestamps ===
I2C1: RTC 0x68 ok, EEPROM 0x50 ok
== EEPROM log: 3 of 511 records ==
  idx  addr    mm:dd:yy hh:mm:ss  raw     %
    0  0x0008  08:08:26 14:30:05  2451   59
    1  0x0010  08:08:26 14:30:10  2447   59
    2  0x0018  08:08:26 14:30:15   986   24
log #3  08:08:26 14:30:20  light=1002 (24%)
```
