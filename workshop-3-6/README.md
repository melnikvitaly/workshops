# Workshop 3-6: Як рахувати оберти двигуна або позицію колеса за допомогою Енкодера

Завдання - Керування сервоприводом
Керувати сервоприводом за допомогою енкодера
Один тік енкодера повертає вал сервоприводу на певний кут у відповідному напрямку
Натискання кнопки енкодера зменшує кут повороту вала сервоприводу удвічі на кожен тік.
Повторне натискання кнопки повертає точність до більшого кута на кожен тік.
Коли вал сервоприводу у крайніх положеннях, програвати короткий сигнал у разі спроби прокрутити вал за межі.
Опційно: довге утримання кнопки переводить вал сервоприводу у центральне положення.
Завдання - Сейф
Використати енкодер для введення пін-коду для “сейфу”
Обертання валу в одному напрямку інкрементує одну цифру коду від 0 до 9
Кількість цифр коду не більше 8 (сто мільйонів комбінацій). Краще менше.
Переповнення це спроба або циклічна зміна цифри - на ваш вибір.
Зміна напрямку обертання валу підтверджує попередню цифру і починає інкрементувати наступну. 
Перший тік у протилежному напрямку - підтвердження попередньої цифри і значення поточної дорівнює 0.
Натискання кнопки енкодера - скидання набраного коду і початок нової спроби
Логувати уведення коду в консолі. Використати `\b` для кращого форматування зміни цифри в консолі.
Лімітувати кількість спроб до 3, RESET це спроба. Коли спроби вичерпано - програти мелодію сигналізації і/або блокувати мікроконтроллер до перезавантаження
Успішне введення коду програє мелодію і/або повертає сервопривід (замок) на певний кут і/або міняє стан реле (надає доступ до обладнання).
Завдання - Калькулятор
Сценарій користувача

Обертанням валу енкодера задати перший операнд
Натиснути кнопку для підтвердження
Обертанням валу енкодера задати операцію (сума, різниця, добуток, частка)
Натиснути кнопку для підтвердження
Обертанням валу енкодера задати другий операнд
Натиснути кнопку для підтвердження
Результат відображається у консолі.
Приклад формату: `234` -> `234 + ` -> `234 + 77` -> `234 + 77 = 311`
Використати `\b` для кращого форматування.
